İşlem Rehberi

İşlem Rehberi, günlük ve resmî işlemler hakkında gerekli belgeleri, kimlerin başvurabileceğini ve izlenecek adımları tek bir yerde anlaşılır biçimde sunmayı amaçlayan bir web projesidir.

Projenin Amacı

Bazı işlemler için gerekli belgeler ve başvuru adımları farklı kurumların internet sitelerine dağılmış olabilir. İşlem Rehberi, kullanıcıların aradıkları rehberi daha kolay bulmasına ve başvuru öncesinde hazırlık yapmasına yardımcı olmak için tasarlanmıştır.

Özellikler

- İşlem rehberleri arasında arama
- Kategoriye göre filtreleme
- Her işlem için ayrı detay ekranı
- Gerekli belgeler için işaretlenebilir kontrol listesi
- İşlem adımlarının sıralı gösterimi
- Kimlerin başvurabileceğine ilişkin genel açıklama
- İlgili resmî kurum sayfasına bağlantı
- Masaüstü ve mobil ekranlara uyumlu arayüz
- 
Mevcut Rehberler

- Burs başvurusu
- Öğrenci belgesi alma
- İş başvurusu
- Pasaport başvurusu
- e-Devlet işlemleri
- Üniversite kayıt işlemleri
- 
Kullanılan Teknolojiler

- HTML5 — sayfa yapısı
- CSS3 — görünüm ve responsive tasarım
- JavaScript — arama, kategori filtreleri, detay pencereleri ve belge kontrol listesi
- 
Projeyi Çalıştırma

Bu prototip için paket yöneticisi veya derleme işlemi gerekmez.
1. Depoyu bilgisayarına indir veya klonla.
2. Proje klasörünü aç.
3. index.html dosyasını bir web tarayıcısında aç.
İstersen yerel geliştirme sırasında Visual Studio Code gibi bir editörün Live Server benzeri özelliğini de kullanabilirsin.# webprojesi
